# <h1 align="center">Logotip - Twitter</h1>

Ta projekt predstavlja simulacijo znaka Twitter, izdelano s pomočjo HTML5, JavaScript, Canvas in SVG. Glavni poudarek projekta je uporaba Bezierjevih krivulj za natančno risanje znaka na podlagi vnaprej določenih kontrolnih točk.

---

## 🚀 Funkcionalnosti

- Risanje znaka Twitter z uporabo Bezierjevih krivulj

- Implementacija risanja s pomočjo:

- Canvas (bezierCurveTo)

- SVG (<path>)

- Prikaz znaka neposredno v brskalniku

- Skalabilna in natančna grafična predstavitev

- Čista in pregledna struktura kode

---

## 🛠️ Uporabljene tehnologije

- **HTML5** – struktura dokumenta

- **CSS3** – osnovno oblikovanje strani

- **JavaScript** – risanje znaka z Canvas API

- **Canvas** – funkcija bezierCurveTo

- **SVG** – risanje znaka s pomočjo <path>

---

## 🎓 Predstavitev

Gre za šolski projekt, izdelan v okviru predmeta NSA4.
Cilj naloge je bil spoznati delovanje Bezierjevih krivulj ter razliko med risanjem grafike s Canvas in SVG.
